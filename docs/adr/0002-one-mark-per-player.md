# One Mark per player

A Mark belongs to the player, not to a particular Echo Fruit. Using any Echo Fruit with no live Mark creates a Mark and does not consume the fruit; using any Echo Fruit with a live Mark teleports and consumes that fruit.

Per-fruit state would look like a two-use item but break "only one Mark at a time" as soon as the player holds two fruits. Player-owned state matches self-only visibility and survives dropping or swapping the item.
